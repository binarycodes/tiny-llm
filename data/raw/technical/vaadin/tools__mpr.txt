Multiplatform Runtime Flow

Note: Commercial Feature

Multiplatform Runtime only works with the Extended Maintenance versions of Vaadin 7 and Vaadin 8.

- Learn More
- See Pricing

Multiplatform Runtime (MPR) makes it possible to run applications and components written with Vaadin 7/8 inside a Vaadin Flow application.

Issues can be reported on the public Multiplatform Runtime repository.
